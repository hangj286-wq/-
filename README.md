# 物語の書架 — 無料の創作作品サイト

## 使い方
1. `index.html` をブラウザで開くと、サイトを確認できます。
2. ファイル下部の JavaScript にある `works` を編集して、作品・各話・本文を追加してください。
3. `characters` を編集すると登場人物を追加できます。
4. サイト名は HTML の「物語の書架」を置換して変更できます。

## GitHub Pages で公開
1. GitHub で Public リポジトリを新規作成します。
2. `index.html` をリポジトリのルートにアップロードします。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. 公開された URL を開いてください。反映まで数分かかる場合があります。

## 注意
- 収録されている小説本文はサンプルです。実際の原稿に差し替えてください。
- 読書文字サイズはブラウザのローカルストレージに保存されます。
- 作品検索はブラウザ内で動き、サーバーやデータベースは必要ありません。
- GitHub Pages は静的サイト向けです。読者ログイン・コメント投稿などの保存機能はありません。
